# ezone

## Hướng dẫn cài đặt

### 1. Chạy Frontend (React)

```bash
cd frontend
npm install
npm run dev
```

## Tài liệu liên quan

Để hiểu rõ hơn về hệ thống, vui lòng tham khảo các tài liệu trong thư mục `docs/`:
- `PRD.md`: Tài liệu đặc tả yêu cầu sản phẩm.
- `ARCHITECTURE.md`: Tài liệu thiết kế kiến trúc tổng thể.
- `DATABASE.md`: Thiết kế cơ sở dữ liệu (13 bảng).
- `API_SPEC.md`: Danh sách chi tiết các API (RESTful).
- `UI-DESIGN.md`: Tài liệu thiết kế giao diện.
- `PROJECT-RULES.md`: Quy chuẩn viết code cho toàn bộ dự án.
